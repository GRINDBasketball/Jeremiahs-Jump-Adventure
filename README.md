# Jeremiah's Jump Adventure!

A jumping platform game designed by Jeremiah. King Scorch took Princess Star, so run, jump and shoot fireballs through 4 castles and King Scorch's spooky lava castle to save her!

- **Move:** ◀ ▶ buttons or arrow keys / A D
- **Jump:** JUMP button, Space or ↑ (land on bad guys to stomp them)
- **Fire:** FIRE button, F or X (fireballs pop coins out of bad guys)
- Bonk the star blocks to find the giant mushroom and grow super big!

Play it here: https://grindbasketball.github.io/Jeremiahs-Jump-Adventure/

One self-contained HTML file with no outside assets. All characters are original.
